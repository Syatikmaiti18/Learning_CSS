# Learning_CSS

Welcome to my **Learning_CSS** repository! 🎨

## 📌 About CSS

**CSS (Cascading Style Sheets)** is a stylesheet language used to style and design web pages. While HTML is used to create the structure and content of a webpage, CSS is used to control how that content looks and is presented to the user.

Through this repository, I am learning how to use CSS to create webpages that are more attractive, organized, responsive, and user-friendly.
